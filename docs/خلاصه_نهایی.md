## 💬 نحوه استفاده

### مرحله 1: دریافت API Key

```bash
# ورود به سیستم
curl -X POST http://localhost:3000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"demo@airouter.dev","password":"demo123"}'

# ساخت API Key
curl -X POST http://localhost:3000/api/v1/auth/api-keys \
  -H "Authorization: Bearer {TOKEN_از_مرحله_قبل}" \
  -H "Content-Type: application/json" \
  -d '{"name":"My Key","permissions":["read","write"]}'
```

### مرحله 2: استفاده از Chat API

```bash
curl -X POST http://localhost:3000/api/v1/chat/completions \
  -H "Authorization: Bearer {API_KEY_شما}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mock-gpt-4",
    "messages": [
      {"role": "user", "content": "سلام! چطوری؟"}
    ],
    "routingStrategy": "cost",
    "enableCache": true
  }'
```

## 🎯 قابلیت‌های اصلی

### 1. Multi-Provider Support
- ✅ OpenAI (آماده - نیاز به API key)
- ✅ Anthropic (آماده - نیاز به API key)
- ✅ Mock Provider (فعال برای تست)

### 2. Routing Strategies
- **Cost-Based**: ارزان‌ترین provider را انتخاب می‌کند
- **Latency-Based**: سریع‌ترین provider را انتخاب می‌کند
- **Priority-Based**: provider دلخواه شما با fallback
- **Fallback**: تلاش با همه providers تا موفق شود

### 3. Response Caching
- کش خودکار با Redis
- صرفه‌جویی در هزینه
- پاسخ فوری برای request‌های تکراری

### 4. Usage Tracking
- ثبت تمام requests
- محاسبه token usage
- محاسبه cost
- ثبت billing events
