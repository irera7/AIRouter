## 🎯 شروع سریع

حالا می‌توانید:
- ✅ API Key بسازید
- ✅ درخواست‌های AI بفرستید
- ✅ آمار و Analytics ببینید
- ✅ (برای Admin) کاربران و سیستم را مدیریت کنید

## 🛠️ اسکریپت‌های مدیریتی

### 1️⃣ راه‌اندازی - `start.sh`

```bash
./start.sh
```

**چه کاری می‌کند:**
- پورت‌های 3000 و 3001 را آزاد می‌کند
- Process های قدیمی را می‌کشد
- Docker را چک و start می‌کند
- Database آماده شدن را منتظر می‌ماند
- Backend و Frontend را start می‌کند
- وضعیت و لینک‌ها را نمایش می‌دهد

**توقف:**
- فقط `Ctrl + C` بزنید

---

### 2️⃣ بررسی وضعیت - `status.sh`

```bash
./status.sh
```

**خروجی نمونه:**
```
📊 AIRouter Status

🐘 PostgreSQL:
   ✓ Running and ready

📦 Redis:
   ✓ Running and ready

🔧 Backend (port 3000):
   ✓ Running and healthy (PID: 12345)
   → http://localhost:3000

🎨 Frontend (port 3001):
   ✓ Running and ready (PID: 12346)
   → http://localhost:3001

✅ All services are running!
```

---

### 3️⃣ راه‌اندازی مجدد - `restart.sh`

```bash
./restart.sh
```

**کاربرد:**
- بعد از تغییرات کد
- برای refresh کردن سیستم
- وقتی مشکلی پیش می‌آید

---

### 4️⃣ توقف - `stop.sh`

```bash
./stop.sh
```

**سوال:**
```
Do you want to stop Docker containers too? [y/N]:
```

- **N** (پیشنهادی): فقط Backend و Frontend متوقف می‌شوند
- **y**: Docker هم متوقف می‌شود

## 🔌 استفاده از API

### نحوه استفاده:

#### 1. ثبت‌نام کاربر جدید

```bash
curl -X POST http://localhost:3000/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "name": "John Doe",
    "email": "john@example.com",
    "password": "secure123"
  }'
```

---

#### 2. ورود و دریافت Token

```bash
curl -X POST http://localhost:3000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "demo@airouter.dev",
    "password": "demo123"
  }'
```

**خروجی:**
```json
{
  "success": true,
  "data": {
    "token": "eyJhbGc...",
    "user": { ... }
  }
}
```

---

#### 3. ساخت API Key

```bash
TOKEN="your-jwt-token"

curl -X POST http://localhost:3000/api/v1/auth/api-keys \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "My API Key"
  }'
```

**خروجی:**
```json
{
  "success": true,
  "data": {
    "key": "sk_abc123...",
    "name": "My API Key"
  }
}
```

---

#### 4. ارسال درخواست Chat Completion

```bash
API_KEY="your-api-key"

curl -X POST http://localhost:3000/api/v1/chat/completions \
  -H "X-API-Key: $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [
      {
        "role": "user",
        "content": "سلام! چه خبر؟"
      }
    ],
    "model": "gpt-4",
    "strategy": "cost-optimized"
  }'
```

**استراتژی‌های Routing:**
- `cost-optimized` - ارزان‌ترین
- `latency-optimized` - سریع‌ترین
- `priority` - بر اساس اولویت
- `fallback` - پشتیبان

---

#### 5. دریافت آمار

```bash
# خلاصه آمار
curl -H "X-API-Key: $API_KEY" \
  http://localhost:3000/api/v1/analytics/summary

# آمار دقیق (7 روز اخیر)
curl -H "X-API-Key: $API_KEY" \
  http://localhost:3000/api/v1/analytics/metrics?timeRange=7d

# آمار Provider ها
curl -H "X-API-Key: $API_KEY" \
  http://localhost:3000/api/v1/analytics/providers

# Export به CSV
curl -H "X-API-Key: $API_KEY" \
  http://localhost:3000/api/v1/analytics/export?format=csv&timeRange=30d \
  -o usage-report.csv
```

## 🔍 عیب‌یابی

### مشکل 1: پورت اشغال است

**خطا:**
```
Error: listen EADDRINUSE: address already in use 0.0.0.0:3000
```

**راه حل:**
```bash
./stop.sh
./start.sh
```

یا دستی:
```bash
# چک کنید چه چیزی روی پورت است
lsof -i :3000
lsof -i :3001

# Kill کنید
kill -9 $(lsof -ti:3000)
kill -9 $(lsof -ti:3001)
```

---

### مشکل 2: Backend start نمی‌شود

**بررسی logs:**
```bash
tail -f /tmp/airouter-backend.log
```

**دلایل احتمالی:**
- Database آماده نیست
- Environment variables درست نیست
- Port اشغال است

**راه حل:**
```bash
# بررسی Docker
docker ps
docker logs airouter-postgres

# Restart کامل
./restart.sh
```

---

### مشکل 3: Frontend start نمی‌شود

**بررسی logs:**
```bash
tail -f /tmp/airouter-frontend.log
```

**راه حل:**
```bash
cd frontend
npm install
cd ..
./restart.sh
```

---

### مشکل 4: Database connection error

**خطا:**
```
Failed to connect to database
```

**راه حل:**
```bash
# بررسی Docker
docker ps | grep postgres

# اگر نیست، start کنید
docker start airouter-postgres

# یا
docker compose up -d postgres

# چک کنید آماده شده
docker exec airouter-postgres pg_isready -U airouter
```

---

### مشکل 5: API Key کار نمی‌کند

**خطا:**
```
{"error": "Unauthorized", "message": "Invalid API key"}
```

**بررسی:**
1. API Key را درست کپی کرده‌اید؟
2. Header درست است؟ باید `X-API-Key` باشد
3. کلید Active است؟

**تست:**
```bash
# بررسی health
curl http://localhost:3000/health

# login و کلید جدید بسازید
curl -X POST http://localhost:3000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"demo@airouter.dev","password":"demo123"}'
```

---

### مشکل 6: همه چیز خراب شد! 😱

**Reset کامل:**
```bash
# 1. توقف همه چیز
./stop.sh
# پاسخ: y (برای stop کردن Docker هم)

# 2. پاک کردن logs
rm /tmp/airouter-*.log
rm /tmp/airouter-*.pid

# 3. شروع مجدد
docker compose up -d postgres redis
sleep 5
./start.sh
```
